# 🛍️ ShopEasy - Online Shopping Store

Welcome to **ShopEasy**, a fast, lightweight, and modern e-commerce web application built for seamless online shopping.

🚀 **Live Demo:** [https://prenchen67-gif.github.io/ShopEasy/](https://prenchen67-gif.github.io/ShopEasy/)

---

## ✨ Features

- 📱 **Fully Responsive Design:** Smooth shopping experience on mobile, tablet, and desktop devices.
- ⚡ **Zero-Downtime Updates:** Automated deployment powered by GitHub Actions.
- 🛒 **Interactive Shopping Cart:** Real-time item count and floating cart shortcut.
- 🚚 **Multiple Payment Method Support:** Fast Cash on Delivery, bKash, Nagad, and Rocket support.
- 🛡️ **Modular Architecture:** Easy product management via separated JavaScript data files (`products.js`).

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Hosting & CI/CD:** GitHub Pages & GitHub Actions
